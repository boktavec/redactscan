---
title: "Scanner interface, registry and scan FILE: fail-closed, isolated scanners over one safely read file"
---

## Outcome

`redactscan scan FILE` reads one file through `safefs.OpenRegular` (never executing it), runs every registered scanner over the same in-memory snapshot, and prints their findings sorted deterministically.

Anything that stops a scanner from running cleanly marks the scan **incomplete** and exits 1, while the other scanners' findings are still shown. That covers an error, a panic, Goexit, an invalid or unredacted finding, cancellation, an over-cap file, too many findings, or no scanner having run.

This story ships no production scanners (REDACT-37 adds the first), so every real scan reports `no scanner ran` and exits 1 until then. Story: [REDACT-36](http://localhost:8080/issue/REDACT-36). Spec: `docs/features/scanner-scan-file/spec.md`. ADR: `docs/adr/0004-scanner-contract-content-and-isolation.md`.

<Callout id="scope-callout" tone="info">

**Non-goals:**

- real scanners (REDACT-37)
- directory walking, worker pool, `scan ./dir` and `internal/ingest` (REDACT-39)
- report format and JSON (REDACT-38)
- a findings-present exit code (REDACT-50)
- per-scanner timeouts, signal handling and concurrency
- stdin input
- `io.ReaderAt` streaming (a planned later change)
- any change to `internal/redactor` (REDACT-16 is changing it in parallel)

</Callout>

<Table

    ["Scan returns an error", "{name, error} (canceled if ctx done)", "That call's findings discarded; error text never printed"],
    ["Finding fails Validate, ArtifactID, bounds or the redactor check", "{name, invalid finding} once per scanner", "Only that finding dropped"],
    ["More than 1000 accepted findings", "{name, too many findings} once per scanner", "First 1000 in registry order kept"],
    ["Ran == 0 (empty, all unsupported, all failed)", "{registry, no scanner}", "stderr: scan incomplete: no scanner ran"]
  ]}

<Callout id="output-callout" tone="warning">

**Untrusted output.**

- `scan` prints only severity, ID, File, Line and Title. Evidence, Description, Category, Metadata, ArtifactID and error or panic values are never printed (canary-tested).
- ID, Title and Evidence must pass `redactor.Redact` with no kind other than label-like.
- ID and Title are at most 128 bytes of UTF-8, File at most 4096 bytes, and Line at least 0.
- ID, File and Title are `strconv.Quote`d, so ESC, CR, bidi overrides and invalid UTF-8 appear escaped.

</Callout>

## Decisions

<Table
  id="decisions-table"
  columns={["Decision", "Why", "Rejected"]}
  rows={[
    ["content []byte read once by the caller (ADR 0004)", "One open, one cap, one snapshot for all scanners; no I/O in scanners", "Each scanner opens a.Path (TOCTOU, N opens); io.ReaderAt now (no need yet, planned later)"],
    ["Over cap: incomplete, no scanners run", "Fail closed without partial-content bugs; one outcome type", "Refuse via a separate path; scan a truncated prefix"],
    ["10 MiB cap (Assumed)", "Matches the redactor; bounded memory per file", "Configurable or larger before measuring"],
    ["readArtifact helper in internal/cli", "Scanner stays I/O-free; no overlap with REDACT-39 ingest", "scanner.ScanFile; waiting for ingest.File"],
    ["Goroutine per call with completed flag", "Survives panic(nil) and Goexit; one bug can't kill a directory scan", "No recovery; recover() != nil only"],
    ["Scanner imports redactor for printed fields", "Defense in depth when a detector forgets to redact", "Contract only; duplicated verifier"],
    ["Explicit registry, no init", "No hidden state; easy test registries", "Global Register()"],
    ["ArtifactID mismatch is an invalid finding", "Keeps reports attributable; exposes the bug", "Overwrite ArtifactID"],
