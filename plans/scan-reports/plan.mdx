title: "Scan reports: readable text and versioned JSON, with every untrusted string neutralised"

## Outcome

`redactscan scan FILE` prints one report on stdout: readable text by default, or a versioned JSON document with `-json`. Both say whether the scan was complete, group findings by severity with evidence and reasoning, list failures, and count findings by severity. Every string derived from scanned content is neutralised by visible escaping, so it cannot drive a terminal or hide text with bidi, zero-width or other invisible characters. Story: [REDACT-38](http://localhost:8080/issue/REDACT-38). Full spec: `docs/features/scan-reports/spec.md`. Decision record: `docs/adr/0005-report-escaping-and-versioned-json.md`. The design includes every item from the security design review.

Concrete example: a scan where scanner `script` reports a curl-pipe-to-shell line whose evidence carries an ANSI colour sequence, and scanner `filetype` panics.

<Callout id="scope-callout" tone="info">

**In scope:** stricter finding checks in `internal/scanner`, a new `internal/report` package (text and JSON renderers, one escaping rule, golden tests), and `scan` wiring with a `-json` flag. **Non-goals:** real scanners (REDACT-37), `scan ./dir` and multi-artifact reports, a findings exit code or policy (REDACT-50), colours, `-format`, SARIF, pretty JSON, changes to `redact`.

</Callout>

<Callout id="stripped-callout" tone="decision">

The story says escape sequences are "stripped". Here **"stripped" means "neutralised by visible escaping"**: a dangerous rune becomes `\x1b`, `\u202e`, `\ufe0f` and so on, never deleted, so tampering stays visible and evidence keeps its meaning.

</Callout>

## Decisions

<Table
  id="decision-table"
  columns={["Decision", "Why", "Rejected"]}
  rows={[
    ["Visible escaping; no quotes except metadata string values; backslash and (in values) quote escaped", "Keeps tampering visible and evidence intact; an attacker cannot forge a fake escape or field boundary", "Deleting runes (hides tampering); quoting every field (noisy)"],
    ["Dangerous = !strconv.IsPrint(r) or Other_Default_Ignorable_Code_Point or Variation_Selector", "IsPrint covers C0, DEL, C1, bidi, zero-width, separators but accepts U+034F, U+3164, U+17B4, U+FE0F, U+E0100 (Verified on go1.27.1). Emoji U+FE0F shows as an escape (accepted)", "IsPrint alone; hand-written range list"],
    ["JSON escapes the same runes as \\uXXXX over the whole output, fail closed on invalid UTF-8", "encoding/json writes DEL, C1, bidi, zero-width raw (Verified on go1.27.1); escapes keep decoding exact", "Plain JSON (scan -json | cat injection); pre-escaped text (lossy)"],
    ["Self-describing document; status only from Result.Incomplete()", "A stdout-only consumer cannot mistake an incomplete scan for a clean one; consumers must also check the exit code and treat empty or unparseable output as failure", "Findings-only JSON with stderr failures (fail open)"],
    ["Integer schema_version 1, bumped only on breaking change", "Simple check for consumers; additive fields need no bump", "Semver or URI version"],
    ["Registry checks: grammars, bounds, redactor (strict for Category and Description), cheap checks first", "The report is the first output to print these fields; enforce the contract where every finding passes. Sizes Assumed", "Report-only placeholder; contract only"],
    ["Every renderer error is exit 3 with a fixed stderr line", "No renderer failure can end in exit 0 or 1", "Ignoring marshal errors"],
    ["Renderer input is scanner.Result; compact JSON; no fmt in report", "No speculative aggregate type; matches redact -json; no reflection formatting of untrusted values", "New report.Report type; indented JSON"]
  ]}
/>

## Report contract

<Table
  id="json-fields"
  columns={["JSON field", "Type", "Rule"]}
  rows={[
    ["schema_version", "integer", "1; first key; changes only on breaking change"],
    ["status", "string", "complete | incomplete, from Result.Incomplete() only"],
    ["summary.total, summary.by_severity", "integer, object", "all five severity names always present"],
    ["findings[]", "array, never null", "id, severity, category, title, description, file, line (0 = unknown), evidence, metadata ({} when empty); ArtifactID not emitted; registry order"],
    ["failures[]", "array, never null", "scanner, reason (constant scanner.Reason)"]
  ]}
/>

<Table
  id="grammar-table"
  columns={["Finding field", "Rule enforced in checkFinding"]}
  rows={[
    ["ID", "^[a-z0-9][a-z0-9._-]*$, 1..128 bytes; redactor clean"],
    ["Category", "empty or ^[a-z0-9][a-z0-9._-]*$, up to 64 bytes; redactor strict (no labels)"],
    ["Description", "valid UTF-8, up to 1024 bytes; redactor strict (no labels)"],
    ["Metadata keys", "^[a-z][a-z0-9_]{0,63}$ (all current ingest keys fit)"],
    ["Metadata string values", "existing bounds; redactor clean"],
    ["Title, File, Evidence", "unchanged bounds; redactor clean"]
  ]}
/>

Text layout: header, `status:` line, severity groups from critical to info (empty groups omitted, `no findings` when none), each finding as `- ID: Title` with indented `file`, `category`, `reasoning`, `evidence`, `metadata` lines (empty ones omitted, metadata keys sorted, string values quoted), an optional `failures (n):` section with fixed registry texts, and a final `summary:` line.

## Risks and follow-ups

<Table
  id="risk-table"
  columns={["Risk", "Handling"]}
  rows={[
    ["Breaking scan output change (failures and summary move to stdout)", "REDACT-36 format was provisional; documented in usage, README and PR"],
    ["Description up to 1 KiB, redactor knows only four formats", "Accepted; threat model records it; REDACT-37 scanners must test that Description and Category are constant"],
    ["Invalid UTF-8 in File becomes U+FFFD in JSON", "Documented; text shows exact \\xNN; file is display only per threat model"],
    ["Legitimate description resembling a secret format or label is dropped", "Fail closed, same as Title today; detectors use constant text"],
    ["Escaping blow-up: text up to 4x, JSON up to 6x, peak about 200 MiB at 1000 maximal hostile findings", "Accepted for a local CLI; escapeJSON pre-sizes its buffer"],
    ["Toolchain Unicode update changes the tables", "Golden and exhaustive rune tests catch it"],
    ["F1: 8-bit C1 (0x9B inside printable UTF-8) on non-UTF-8 terminals", "Accepted risk, recorded in threat model"],
