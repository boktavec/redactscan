---
title: "Recursive directory ingestion: a safe walker that never follows a symlink, never hangs, never leaves the root"
---

## Outcome

`ingest.Walk(root, ingest.Limits{})` turns an untrusted directory tree into `artifact.Artifact` values for its regular files and `finding.Finding` values for everything it skipped. It never follows a symlink, never blocks on a FIFO, never leaves the root (even if entries are swapped mid-walk), keeps memory bounded, and never lets a partial walk look complete. This is the base a later `scan ./project` command builds on. Story: [REDACT-39](http://localhost:8080/issue/REDACT-39). Full spec: `docs/features/recursive-ingest/spec.md`.

Concrete example: a cloned repo `./project` holds `src/main.go`, `docs -> ../../.ssh`, `loop -> loop`, a FIFO `build/pipe` and a 70-level directory chain. `Walk("./project", ingest.Limits{})` returns an Artifact for `src/main.go` (`Path` = `./project/src/main.go`), Findings `ingest-symlink` (medium, `link_kind=escape`), `ingest-symlink` (low, `link_kind=loop`), `ingest-special-file` (low, `file_type=fifo`), one `ingest-incomplete` (medium, `depth_skipped=1`), and the error `ingest.ErrIncomplete`. A caller that writes `if err != nil { return err }` stops: fail closed by default.

<Callout id="scope-callout" tone="info">

**Non-goals:** a `scan` CLI command or report format; reading file contents (`MIMEType` and `SHA256` stay empty); `.git` special handling (walked as an ordinary directory); single-file, archive, git or URL ingest; `context.Context` and timeouts; staying on one filesystem; a total path-bytes budget; Windows; escaping control characters in names (output story).

</Callout>

<Callout id="openroot-decision" tone="decision">

**Children are opened with `Root.OpenFile(name, O_RDONLY|O_DIRECTORY|O_NONBLOCK)`, never `Root.OpenRoot(name)`.** `OpenRoot` blocks forever on a FIFO swapped in for a directory and follows a final in-root symlink. With `O_DIRECTORY` a FIFO or a symlink to one fails at once with `ENOTDIR`. An in-root symlink to a directory opens, but the `SameFile` check against the earlier `Lstat` result catches it (`ingest-changed`). **Verified** on macOS with go1.27.2 using a scratch probe: `OpenRoot(fifo)` hung for more than 2 s; `OpenFile` with `O_DIRECTORY` returned `ENOTDIR` for both FIFO cases; for the in-root symlink, `sameAsLstat=false`. **Assumed** for Linux until step 1 pins it with tests.

</Callout>

## API

<Code
  id="api-code"
  filename="internal/ingest/ingest.go"
  language="go"
  code={"const (\n\tDefaultMaxDepth   = 64\n\tDefaultMaxEntries = 100_000\n\tMaxMaxDepth       = 256       // one open descriptor per level\n\tMaxMaxEntries     = 1_000_000\n\tMaxPathBytes      = 1024      // macOS PATH_MAX; applied on every OS\n)\n\ntype Limits struct {\n\tMaxDepth   int // 0 means DefaultMaxDepth; negative or > MaxMaxDepth is ErrInvalidLimits\n\tMaxEntries int // 0 means DefaultMaxEntries; counts every directory entry\n}\n\ntype Result struct {\n\tArtifacts []artifact.Artifact\n\tFindings  []finding.Finding\n}\n\nvar (\n\tErrIncomplete    = errors.New(\"ingest: scan incomplete\") // partial Result; never clean\n\tErrInvalidLimits = errors.New(\"ingest: invalid limits\")\n\tErrInvalidRoot   = errors.New(\"ingest: invalid root\")\n\tErrInternal      = errors.New(\"ingest: internal error\")\n)\n\nfunc Walk(root string, lim Limits) (Result, error)\n\n// internal/safefs (PR 1)\nvar ErrNotDir = errors.New(\"safefs: not a directory\")\nfunc OpenDirRoot(path string) (*os.File, *os.Root, error)\nfunc OpenChildDir(parent *os.Root, name string, want fs.FileInfo) (*os.File, *os.Root, error)"}
/>

Artifacts: `ID = "a-<n>"` in walk order (stable for an unchanged tree because each directory is sorted); `Path` = root as typed (trailing `/` trimmed, `/` kept, no `Clean`) + `/` + `RelativePath`, so `safefs.OpenRegular` re-checks it independently; `RelativePath` and `Name` are substrings of `Path`; `Size` from `Lstat`; `Source.Type = artifact.SourceDirectory`. Fatal errors (`ErrInvalidRoot`, `ErrInvalidLimits`, `ErrInternal`, `safefs.ErrSymlink`, `safefs.ErrNotDir`, `ErrChanged`, `ErrUnsupportedPlatform`) return an empty `Result`. The only non-fatal error is `ErrIncomplete`.

## Symlink classification (PR 3)

Classification uses `top.Stat(rel)` on the **top** root with the slash-joined relative path. The child root would report an in-root sibling link such as `a/b/c -> ../d` as an escape.

<Table
  id="symlink-table"
  columns={["top.Stat(rel)", "link_kind", "Severity"]}
  rows={[
    ["nil", "in-root", "info"],
    ["errors.Is ELOOP (also chains over the link limit)", "loop", "low"],
    ["errors.Is fs.ErrNotExist", "dangling", "info"],
    ["*fs.PathError with a non-Errno inner error (\"path escapes from parent\", empty target), or EXDEV", "escape", "medium"],
    ["anything else, such as EACCES on a middle component", "unknown, with errno", "medium"]
  ]}
/>

**Verified** on macOS with go1.27.2 using a scratch probe: in-root returns nil; dangling matches `fs.ErrNotExist`; self and two-link loops match `ELOOP`; relative, absolute, chained and missing-target escapes return a `*fs.PathError` wrapping an unexported `errors.errorString`, not an `Errno`. **Assumed:** Linux behaves the same, and the `EXDEV` mapping only covers the case where it does not. Step 1 pins this in a Linux container and stops for re-planning if the table cannot cover what it finds.

## Accepted risks

<Callout id="risks-callout" tone="risk">

- **Directory moved out of the root while its descriptor is held:** it is listed once under its old relative path. The walk never resolves a name outside the root.
- **Hard links:** a hard link to a file outside the tree is listed as a regular file. Future archive extraction must refuse hard links and absolute or escaping link targets.
- **Mount points:** the walk crosses them. Scanning `/` lists `/proc/self/environ` as a regular file (listed only, never read here) and skips `/dev` devices.
- **No timeout:** a hung network filesystem can block the walk.
- **Budget cut inside a directory:** which entries are kept depends on filesystem order. The walk is reported incomplete.
- **Memory:** worst case about 215 MB allocated and about 126 MiB retained for 100,000 Artifacts with 1015-byte paths (**Verified** by benchmark: about 1.04 KiB allocated per short-path Artifact, about 2.1 KiB at maximum length; retained about 275 B per short-path Artifact, the 126 MiB is extrapolated).
- **Symlink classification CPU (user-accepted):** `Root.Stat` costs one `openat` per target component over up to 8 chained links, bounded by target length times hops and not by `MaxDepth` or `MaxEntries`. Hostile deep links were measured at about 4,500x (macOS) and about 80x (Linux) a short link. No timeout or step budget now; a classification step budget is the recommended hardening before untrusted uploads or MCP. See the threat model.
- **Descriptors:** at most `MaxDepth + 2` (briefly `MaxDepth + 4` while classifying a symlink; an `EMFILE` there gives `unknown`, errno 24, and does not make the walk incomplete). `MaxDepth` near the 256 cap can hit the macOS default soft limit (**Assumed** 256). That surfaces as a read error and an incomplete walk, not a crash.

</Callout>

## Verification

- `task test` after each step. Before each PR is marked ready, `task verify` must pass: fmt, lint, test, cross, gosec, govulncheck, gitleaks.
- Linux run in each PR, since CI runs no Go tests: `docker run --rm -v "$PWD":/src -w /src golang:1.27 go test ./...`, with the result recorded in the PR.
- Break-the-guard check, then revert. Each change must make its matching test fail:
  - drop `O_DIRECTORY` in `OpenChildDir`
  - drop the `SameFile` check
  - classify against the child root
  - drop the `ingest-incomplete` Finding
- Manual check: build a temp tree with an escaping symlink, a loop, a FIFO and a deep chain. Run a small `go test -run` that prints Finding kinds and counters, and confirm `ErrIncomplete` is returned with no hang.
- Reviews: `staff-engineering-reviewer` and `security-reviewer` on each PR.
